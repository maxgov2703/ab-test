# A/B-тестирование: Оценка эффективности нового дизайна кнопки

## Описание проекта
В данном проекте проведен полный цикл A/B-тестирования для оценки влияния нового дизайна кнопки оформления заказа на Conversion Rate (CR) пользователей.

## Инструменты и библиотеки
* Python (Pandas, NumPy, SciPy, Statsmodels)
* Seaborn, Matplotlib
* Jupyter Notebook / Google Colab

## Этапы исследования
1. **Расчет размера выборки (Sample Size):** Для уровня значимости $\alpha = 0.05$ и мощности $80\%$ определен необходимый размер выборки — **3 835 пользователей на группу**.
2. **Анализ результатов:**
   * **Группа A (Контроль):** CR = 9.60%
   * **Группа B (Тест):** CR = 11.55%
   * **Относительный прирост (Uplift):** +20.38%
3. **Статистическое тестирование:**
   * Использован двухвыборочный Z-тест для пропорций.
   * Получено $p$-value = 0.005354 ($p < 0.05$).

## Бизнес-вывод
Разница между группами является статистически значимой. Рекомендуется внедрять новый дизайн кнопки на всех пользователей продукта.
